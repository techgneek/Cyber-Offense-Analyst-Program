# Cryptographic Failures Worksheet

Use this worksheet when practicing a cryptographic-failure remediation and retest.

## Before State

- Identify the sensitive value or stored artifact.
- Capture how it is protected today.
- Record why that protection is weak.

## Remediation

- Replace the weak handling with a safer control.
- Keep the change limited to the exercise scope.
- Avoid introducing new dependencies unless needed.

## Retest

- Re-run the same check that exposed the weakness.
- Confirm the improved handling is in place.
- Capture before-and-after evidence.

## Notes

- What changed?
- What proof did you collect?
- What would you tell a reviewer in one paragraph?
