# Security Logging And Monitoring Failures Worksheet

Use this worksheet when practicing a logging and monitoring remediation and retest.

## Before State

- Identify the action that should have produced telemetry.
- Capture what logs or alerts are missing.
- Note why the gap matters.

## Remediation

- Add the missing telemetry or alerting path.
- Keep the fix narrow and reviewable.
- Preserve the lab-only scope.

## Retest

- Trigger the same action again.
- Confirm the log, alert, or audit record appears.
- Capture before-and-after evidence.

## Notes

- What changed?
- What proof did you collect?
- What would you tell a reviewer in one paragraph?
