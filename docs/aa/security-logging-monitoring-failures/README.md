# Security Logging And Monitoring Failures Remediation

## Overview

This investigation package is the archive home for a training exercise focused on weak logging, alerting, and audit visibility.

Use it to practice adding the missing telemetry, tightening the alert path, and proving the fix with retest evidence.

## Featured Training Question

- How Do We Improve Security Logging And Alerting?

## Practice Goal

Show how the case changes when missing logs or alerts are added and verified.

## Suggested Learning Flow

1. Capture the before state.
2. Identify the missing log or alert.
3. Apply the smallest visibility improvement.
4. Retest the same action.
5. Record the evidence.

## Evidence To Store

Use the repository evidence folder for screenshots, exports, and short notes tied to the exercise.

## Case File Questions

- What was not being logged or alerted?
- What control changed?
- What proved the fix worked?
