# Phase 7 Practice Exercise

Use this exercise when you want to learn the remediation-and-retest loop without touching a real production system.

## Scenario

Open the coaching path called:

- How Do We Remediate And Retest A Header Regression?

## What To Capture

Take screenshots or notes for these checkpoints:

1. The scenario selected in the mentor UI.
2. The coaching prompt loaded into chat.
3. The before-state evidence that explains the issue.
4. The remediation change that was made.
5. The retest result that proves the fix.
6. The metrics or workbook update that records the closure.

## How To Think About It

- Start with the smallest safe issue.
- Describe what was wrong in one sentence.
- Make one change.
- Prove the result with the same check you used before.
- Save only the evidence that supports the learning point.

## Suggested Write-Up

When you finish, record three short notes:

- What was the issue?
- What changed?
- What proved it was fixed?

That is enough for a clean practice loop.
